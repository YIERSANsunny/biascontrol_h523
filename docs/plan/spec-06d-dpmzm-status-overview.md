## 2. DPMZM 最终目标

当前 DPMZM 线路的最终目标不是“在旧 MZM 固件上加几个命令”，而是建立一套完整的 DPMZM 偏压控制链路。

### 2.1 近程目标: 开环实验固件

先做一版 **DPMZM 开环实验固件**，支持:

- 三路偏压: `I / Q / P`
- 双导频: `fI / fQ`
- 多频检测:
  - `fI`
  - `fQ`
  - `|fI-fQ|`
  - `fI+fQ`
- 三类扫描:
  - `I/Q MATP`
  - `P QTP`
  - `I/Q MITP`
- 串口输出统一格式:
  - `DPMZMCSV`
  - `DPMZMRAW`
  - `DPMZMSUM`

### 2.2 中程目标: 板上判据与候选点解释

在开环扫描跑通之后，再增加板上解释层，例如:

- MATP 主解 / 隐式解区分
- QTP 主判据 / 辅判据融合
- MITP 分支区分
- 工作点候选分类与筛选

### 2.3 远程目标: 自动闭环控制

最终才进入真正的 DPMZM 自动控制阶段，例如:

- 顺序锁定 `I-MATP -> Q-MATP -> P-QTP -> I-MITP -> Q-MITP`
- 板上自动扫描与自动切换阶段
- 板上闭环 PID 或更高层策略

## 3. 当前开发原则

当前 DPMZM 路线有一个重要约束:

**尽量不破坏原有 MZM 主线逻辑。**

更具体地说:

- 原 `app_main.c` 保留为主入口
- 原 `ctrl_bias.c` 保留为 MZM 控制主循环
- 原 `ctrl_modulator_mzm.c` 保留为 MZM 策略实现

DPMZM 通过 **平行新增文件** 的方式推进，而不是大面积侵入旧 MZM 主线。

这样做的目的很明确:

- 不把已经验证过的 MZM 路径改坏
- DPMZM 可以单独演进
- 方便后续回退、对比、拆分

## 6. 当前最关键的未决科学问题

### 6.1 现象

当前实测中，一个非常关键的问题仍然没有完全搞清楚:

**为什么 `0.2 kHz` 和 `2.2 kHz` 明显不对称。**

理想情况下:

- `0.2 kHz = |fI-fQ|`
- `2.2 kHz = fI+fQ`

二者都来自同一个乘积项:

\[
\sin(\omega_I t)\sin(\omega_Q t)
= \frac{1}{2}\cos(\omega_I-\omega_Q)t
- \frac{1}{2}\cos(\omega_I+\omega_Q)t
\]

因此在理想模型下，二者通常应为同源、同阶、幅度接近。

但实测中看到的是:

- `0.2 kHz` 往往明显更强
- `2.2 kHz` 往往明显更弱
- `2.2 kHz` 附近还常出现 `2.0 kHz` 与 `2.4 kHz`

### 6.2 当前已经确认的内容

我们已经确认:

1. **这不只是 FFT 分辨率问题**
   - 在 `7680` 点、`64 kSPS` 下，`RBW = 8.33 Hz`
   - 已经足够把 `2000 / 2200 / 2400 Hz` 分开

2. **`2200 Hz` 附近确实存在邻近二次谐波**
   - `2fI = 2000 Hz`
   - `fI+fQ = 2200 Hz`
   - `2fQ = 2400 Hz`

3. **当前某些偏置点下，`2200 Hz` 本身真的比 `2000 / 2400 Hz` 弱**
   - 不是简单因为分辨率不够而“糊掉”
   - 而是频谱上它本来就更低

4. **`0.2 kHz` 很可能混有更多非理想贡献**
   - 低频拍频
   - 幅度不平衡
   - 包络起伏
   - 慢漂移 / DAC 非理想 / 调制器非理想

### 6.3 当前最可能的解释

现在最合理的中间判断是:

- `0.2 kHz` 不是纯粹的理想差频交调项，里面掺了更多低频非理想分量
- `2.2 kHz` 更接近真正的和频交调项，但在实际链路中被 `2fI / 2fQ` 等二次谐波夹在中间，且本身较弱

所以:

- `0.2 kHz` 往往“更好看”
- 但不一定“更干净”
- `2.2 kHz` 往往更弱
- 但反而更像真实 `QTP` 主判据

### 6.4 当前还没有最终证明的点

还没有彻底证明:

- `0.2 kHz` 到底有多少比例来自真实差频交调
- `0.2 kHz` 有多少比例来自额外拍频/杂散/包络
- `2.2 kHz` 被压低的主因到底是哪一个:
  - `2fI`
  - `2fQ`
  - 频响不平坦
  - 失真项
  - DPMZM 偏置状态不理想

## 7. 当前最值得优先做的验证

### 7.1 验证 `200 / 2200 / 2000 / 2400 Hz` 的联动关系

推荐实验:

- 固定 `Q、P`，细扫 `I`
- 同时记录:
  - `200 Hz`
  - `2000 Hz`
  - `2200 Hz`
  - `2400 Hz`

目标:

- 看 `2200 Hz` 是不是跟 `2000/2400 Hz` 一起起伏
- 看它是不是被邻近谐波主导

### 7.2 验证 `P` 对 `2200 Hz` 的专属性

推荐实验:

- 固定 `I/Q`
- 细扫 `P`
- 同时记录 `200 / 2000 / 2200 / 2400 Hz`

目标:

- 如果 `2200 Hz` 明显随 `P` 变化，而 `2000/2400 Hz` 相对稳定
- 则说明 `2200 Hz` 仍然保留了较强的 `P` 路判据意义

### 7.3 改导频幅度，看增长规律

推荐实验:

- 固定偏置
- 用多组导频幅度:
  - `200 mVpp`
  - `400 mVpp`
  - 更高但仍安全的幅度
- 比较 `200 Hz` 和 `2200 Hz` 的增长趋势

目标:

- 看哪个频点更符合真正二阶项的增长规律

## 8. 当前状态一句话总结

当前 DPMZM 代码和实验已经进入 **“真实链路可扫、可采、可分析”** 阶段。  
理论、仿真、固件、串口、扫描、FFT 这些基础能力已经基本具备。

现在最核心的未决问题，不再是“代码能不能跑”，而是:

**如何正确解释真实链路里 `0.2 kHz` 与 `2.2 kHz` 的不对称，以及谁才是更可靠的 `P-QTP` 判据。**
