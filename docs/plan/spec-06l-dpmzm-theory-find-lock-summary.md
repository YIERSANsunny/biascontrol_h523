# Spec 06L - DPMZM 理论、找点策略与闭环控制总结

日期: 2026-05-12

状态: 阶段性总结 / 可用于 PPT 与实验报告

用途: 汇总当前 DPMZM 最小-最小-正交偏压控制方案的理论依据、自动找点策略、隐式解处理、RF 对 P-QTP 的影响, 以及闭环控制策略。

---

## 1. 控制目标

本项目的目标是让 DPMZM 稳定工作在:

```text
I-MITP + Q-MITP + P-QTP
```

也就是:

| 通道 | 目标工作点 | 主要检测频率 | 控制目标 |
| --- | --- | --- | --- |
| I 路 | MITP, 最小传输点 | 1000 Hz = fI | I 路一阶导频功率最小 |
| Q 路 | MITP, 最小传输点 | 1200 Hz = fQ | Q 路一阶导频功率最小 |
| P 路 | QTP, 正交点 | 2200 Hz = fI + fQ | I/Q 交调和频项功率最小 |

当前不把 `200 Hz = |fI - fQ|` 作为主控制指标。实验中 200 Hz 受低频干扰明显, 更适合作为辅助观测或健康状态参考, 不适合作为第一版闭环主误差信号。

最终系统需要同时满足三件事:

- I/Q 两路尽可能压低载波泄漏和一阶导频残余。
- P 路把 I/Q 合成后的交调项压到最小。
- 三路偏压能够在温漂、器件漂移和噪声下长期保持稳定。

## 2. 理论基础

### 2.1 DPMZM 输出功率主模型

当前理论模型中, 光电探测后的理想输出项可写为:

$$
I_{id} =
\frac{\eta P_{in}}{8}
\left[
2 + \cos(\varphi_I) + \cos(\varphi_Q)
+ 4\cos\left(\frac{\varphi_I}{2}\right)
\cos\left(\frac{\varphi_Q}{2}\right)
\cos(\varphi_P)
\right]
$$

其中:

| 符号 | 含义 |
| --- | --- |
| $\varphi_I$ | I 路瞬时相位, 包含直流偏压和 I 路导频 |
| $\varphi_Q$ | Q 路瞬时相位, 包含直流偏压和 Q 路导频 |
| $\varphi_P$ | P 路主调制器偏置相位 |
| $P_{in}$ | 输入光功率 |
| $\eta$ | 光电探测和链路增益系数 |

这个公式说明 DPMZM 三路不是相互独立的。I/Q/P 任一路偏压变化都会通过余弦项影响最终光电输出, 所以不能把 DPMZM 当作三个完全独立的 MZM 来控制。

### 2.2 非理想项

真实器件存在:

- 有限消光比。
- 分光比不均。
- 上下臂不完全对称。
- I/Q/P 三路耦合。
- 光电链路噪声和低频漂移。

理论中可用 $\delta_I$, $\delta_Q$, $\delta_P$ 表示这些非理想扰动。非理想项会造成:

- I/Q 一阶谷底偏移。
- P 路 QTP 偏离理论 90 度。
- 隐式解出现。
- 正负支路不完全对称。
- 某些调制器上 MATP/MITP 曲线出现畸变。

因此真实控制点不能只靠理想相位判断, 必须以实际测得的频率分量为准。

### 2.3 I 路一阶项

I 路一阶导频分量可概括为:

$$
I_I \propto
\sin\left(\frac{\phi_I}{2}\right)
\left[
\cos\left(\frac{\phi_I}{2}\right)
+ \cos\left(\frac{\phi_Q}{2}\right)\cos(\phi_P)
\right]
$$

这个式子揭示了两个零点来源:

```text
显式零点:
sin(phi_I / 2) = 0

隐式零点:
cos(phi_I / 2) + cos(phi_Q / 2) cos(phi_P) = 0
```

显式零点通常对应 MATP 附近, 是稳定的相位锚点。隐式零点由 Q/P 两路状态耦合产生, 可能表现为假谷底, 但不一定是我们真正想要的 MATP 或 MITP。

Q 路一阶项与 I 路同理:

$$
I_Q \propto
\sin\left(\frac{\phi_Q}{2}\right)
\left[
\cos\left(\frac{\phi_Q}{2}\right)
+ \cos\left(\frac{\phi_I}{2}\right)\cos(\phi_P)
\right]
$$

### 2.4 P 路交调项

P 路 QTP 依赖 I/Q 导频交调项, 主导项为:

$$
I_{I\_Q} \propto
\sin\left(\frac{\phi_I}{2}\right)
\sin\left(\frac{\phi_Q}{2}\right)
\cos(\phi_P)
$$

更完整地看, 交调项还包含非理想补偿项:

$$
\begin{aligned}
I_{I\_Q} \propto
& (1 + \delta_I + \delta_Q + \delta_P)
\sin\left(\frac{\phi_I}{2}\right)
\sin\left(\frac{\phi_Q}{2}\right)
\cos(\phi_P) \\
& - \delta_I
\cos\left(\frac{\phi_I}{2}\right)
\sin\left(\frac{\phi_Q}{2}\right)
\sin(\phi_P) \\
& + \delta_Q
\sin\left(\frac{\phi_I}{2}\right)
\cos\left(\frac{\phi_Q}{2}\right)
\sin(\phi_P)
\end{aligned}
$$

理想器件中, P-QTP 满足:

$$
\cos(\phi_P) = 0
$$

即 $\phi_P = 90^\circ$。实际器件中, 由于非理想项存在, 真实 QTP 会偏离理论 90 度。这个偏移不是错误, 而是系统为了抵消器件失配而产生的实际最优点。

## 3. 关键物理认识

### 3.1 MATP 不是最终工作点

I/Q 最终目标是 MITP, 但不能一开始直接找 MITP。原因是 MITP 处的一阶导频值会受到其他两路状态影响。

以 I 路为例:

$$
I_I \propto
\sin\left(\frac{\phi_I}{2}\right)
\left[
\cos\left(\frac{\phi_I}{2}\right) + C
\right]
$$

其中:

$$
C = \cos\left(\frac{\phi_Q}{2}\right)\cos(\phi_P)
$$

在 MITP:

```text
phi_I = pi
sin(phi_I / 2) = 1
cos(phi_I / 2) = 0

I_I ∝ C
```

由于 $C$ 取决于 Q/P 状态, MITP 不一定表现为稳定可识别的谷底。

在 MATP:

```text
phi_I = 0
sin(phi_I / 2) = 0

I_I = 0
```

MATP 由外部正弦因子强制清零, 因此更适合作为粗定位相位锚点。

结论:

```text
MATP = 相位参考锚点
MITP = I/Q 最终目标点
```

### 3.2 为什么要从 MATP 推离到平台区

P-QTP 依赖:

$$
I_{I\_Q} \propto
\sin\left(\frac{\phi_I}{2}\right)
\sin\left(\frac{\phi_Q}{2}\right)
\cos(\phi_P)
$$

如果 I/Q 停在 MATP:

```text
sin(phi_I / 2) ≈ 0
sin(phi_Q / 2) ≈ 0
```

则 P 路交调项几乎消失, P 路失去可观测性。也就是说, I/Q MATP 附近是 P-QTP 的盲区。

因此, 完成 I/Q MATP 粗定位后, 要从 MATP 附近推离, 选择一个一阶功率较高、较宽、较连续的平台区作为 P-QTP 粗扫的 I/Q 初始点。

### 3.3 隐式解会造成假谷底和假平台

一阶项存在隐式零点:

$$
\cos\left(\frac{\phi_I}{2}\right)
+ \cos\left(\frac{\phi_Q}{2}\right)\cos(\phi_P) = 0
$$

因此 I/Q 扫描曲线可能出现:

```text
真实谷底 ---- 一阶功率最大点 A ---- 隐式解/假谷底 ---- 一阶功率最大点 B ---- 真实谷底
```

这会导致两个问题:

- 算法把隐式解当成真实 MATP/MITP。
- 算法把被隐式解切断的平台误认为两个独立平台。

所以平台选择不能只依赖“两个谷底之间取中心”。还要判断平台是否连续、是否足够宽、是否不贴边、是否由单点毛刺支撑、以及后续 P-QTP 是否真的可观测。

### 3.4 RF 对 P-QTP 的影响

从导频偏压控制公式看, 2200 Hz 交调项不显式依赖 RF。理论上只靠 I/Q 导频也应该存在:

```text
fI + fQ = 1000 Hz + 1200 Hz = 2200 Hz
```

但实验中观察到:

```text
无 RF: P-QTP 曲线浅, 抖动大, 2200 Hz 可能接近噪声或杂散
有 RF: P-QTP 曲线明显更清晰, 谷底更可观测
```

更合理的工程理解是:

```text
2200Hz_total = 2200Hz_pilot_only + 2200Hz_RF_assisted
```

无 RF 时:

```text
2200Hz_total ≈ 2200Hz_pilot_only
```

有 RF 时:

```text
2200Hz_total ≈ 2200Hz_pilot_only + RF 边带/平均光功率参与后的交调响应
```

因此 P-QTP 扫描和闭环应尽量在实际 RF 工作状态下完成。否则可能找到的是无 RF 条件下的弱交调点, 不一定对应真实工作时的最佳点。

## 4. 自动找点策略

### 4.0 实验前置条件

在执行自动找点前, 需要保证实验工况一致。否则即使算法正确, 扫描曲线也可能失真。

| 条件 | 要求 | 原因 |
| --- | --- | --- |
| DAC 供电 | DAC 模拟侧供电正常 | 否则偏压实际输出不可信 |
| 连续导频 | `pilot-open on` 或等价连续导频状态 | 扫描指标依赖 1000 Hz / 1200 Hz 导频 |
| ADC 频点 | ADC 采样率、Goertzel 频点、电脑端 FFT 一致 | 频点错配会导致功率低十几到二十 dB |
| RF 工况 | 与目标工作状态一致, 尤其 P-QTP 建议 RF 打开 | 2200 Hz 交调项在 RF 打开时更可观测 |
| 串口日志 | 保存 serial log、progress log、metrics CSV | 便于复盘候选点、DC、曲线质量 |

当前推荐串口流程:

```text
dpmzm lock stop
dpmzm set dump metrics
dpmzm set pilot-open on
dpmzm auto coarse
dpmzm auto fine
dpmzm lock start
dpmzm lock status
```

对应脚本入口:

```text
tools/run_dpmzm_firmware_auto_flow_com8.bat
```

脚本主要负责串口编排、保存日志和画图; 找点与闭环的核心逻辑应尽量固化到固件中, 避免脚本和固件行为不一致。

### 4.1 总流程

当前自动找点流程可以总结为:

```text
1. 停止旧闭环
2. 打开连续导频
3. I-MATP 粗扫
4. Q-MATP 粗扫
5. 从 I/Q MATP 曲线中提取高一阶功率平台
6. 固定 I/Q 平台点, 扫 P-QTP
7. 固定 Q/P, 扫 I-MITP
8. 固定 I/P, 扫 Q-MITP
9. 再次优化 P-QTP
10. 小窗口复查 I/Q
11. 启动闭环控制
```

### 4.2 默认工程参数

| 阶段 | 扫描范围 | 步进 | blocks | 指标 |
| --- | --- | --- | --- | --- |
| I-MATP 粗扫 | -9 V 到 +9 V | 0.5 V | 4 | 1000 Hz |
| Q-MATP 粗扫 | -9 V 到 +9 V | 0.5 V | 4 | 1200 Hz |
| P-QTP 粗扫 | -9 V 到 +9 V | 0.5 V | 10 | 2200 Hz |
| I-MITP 粗扫 | -9 V 到 +9 V | 0.5 V | 4 | 1000 Hz + DC |
| Q-MITP 粗扫 | -9 V 到 +9 V | 0.5 V | 4 | 1200 Hz + DC |
| P-QTP 精修 | 小窗口 / 三点法 | 0.01 V 量级 | 10 | 2200 Hz |
| I/Q 小窗复查 | 当前点附近 | 0.01 V | 4 | 一阶 + DC |

P 路使用更多 blocks, 因为 2200 Hz 交调项通常比 I/Q 一阶项更弱, 需要更高平均次数。

### 4.3 I/Q MATP 平台提取

I/Q MATP 粗扫的目的不是直接给最终工作点, 而是给 P-QTP 提供高可观测性的 I/Q 初值。

平台选择原则:

```text
优先选择连续高一阶功率区域
平台越宽越可信
平台不能太贴近扫描边界
平台不能只由单点毛刺支撑
要避开 MATP 盲区
要警惕隐式解切断平台
```

理想情况:

```text
真实 MATP 谷底 ---- 高一阶功率平台 ---- 真实 MATP 谷底
```

复杂情况:

```text
真实谷底 ---- 平台 A ---- 隐式解 ---- 平台 B ---- 真实谷底
```

在复杂情况下, 平台 A 和平台 B 都可能是可用候选。后续最好通过短 P-QTP 验证判断哪个平台真的能让 2200 Hz 曲线出现清晰谷底。

平台评分建议同时考虑功率高度和平台宽度:

```text
score = power_score * width_score
```

其中:

```text
power_score: 平台区域内归一化一阶功率, 功率越高得分越高
width_score: 平台连续宽度, 平台越宽得分越高
```

工程含义:

- 一阶功率高, 说明该点已经离开 MATP 盲区。
- 平台较宽, 说明该区域对小扰动不敏感, 不容易因为粗扫误差或噪声掉出可观测区。
- 只靠单点最高功率不可靠, 因为单点可能是毛刺或隐式解附近的局部异常。

当前为了缩短扫描时间, 可以先选每路得分最高的平台点。后续如果某些调制器仍然找错, 再扩展为每路取前 2 个平台候选, 组合后用短 P-QTP 验证。

### 4.4 P-QTP 粗扫

P-QTP 粗扫时:

```text
固定 I = I 平台中心
固定 Q = Q 平台中心
扫描 P
提取 2200 Hz = fI + fQ
寻找局部谷底
```

可信 P-QTP 曲线应满足:

- 2200 Hz 有足够动态范围。
- 谷底不是第一个点或最后一个点。
- 谷底附近有连续下降和上升趋势。
- 不是单点异常噪声。
- 在 RF 工作状态下能重复出现。

如果 P-QTP 曲线整体很浅或很抖, 应优先怀疑:

- RF 未打开或工况不一致。
- I/Q 平台点对 P 路交调不敏感。
- 2200 Hz 信号接近噪底。
- 当前调制器存在强隐式解或分支畸变。

建议增加 P-QTP 曲线质量判据。当前可先采用保守规则:

```text
1. 最小点不能是扫描第一个点或最后一个点。
2. 最小点左右至少各有一个点高于谷底。
3. 谷底附近应有连续下降/上升趋势, 不能只靠单点突刺。
4. 粗扫动态范围过小则判为弱可观测, 不直接信任该 P 点。
5. 若 RF 关闭且 P-QTP 很浅, 优先判为工况不适合 P 路找点。
```

动态范围门限不宜一开始写死。经验上:

```text
< 5 dB: 高风险, 很可能是噪声或弱交调
5~10 dB: 可疑, 需要结合曲线形状和重复性
> 10 dB: 相对可信
```

这个门限后续应根据不同调制器和 RF 工况继续校准。

### 4.5 I/Q MITP 选择

I/Q 最终 MITP 不能只看一阶最小, 也不能只看 DC 最小。

当前策略:

```text
先找所有合法的一阶局部谷底
再在局部谷底候选中比较 DC
优先选择 DC 更低的局部谷底
```

原因:

```text
一阶局部谷底 -> 说明接近导频一阶抑制点
DC 更低 -> 说明光泄漏和载波残余更小
```

如果只看一阶最小, 可能选到隐式解或错误支路。如果只看 DC 最小, 可能选到不是 MITP 的低光功率点。

### 4.6 P 路再次修正

I/Q 从平台点移动到 MITP 后, P-QTP 会改变。因此流程中必须再次修正 P 路:

```text
I/Q 平台点 -> 第一次 P-QTP
I/Q MITP -> 第二次 P-QTP
```

如果 I/Q 后续小窗口复查又改变了偏压, P 路也可能需要最后再做一次小窗口修正。

## 5. 三点转折搜索与小窗口精修

为了减少扫描时间, 细扫阶段不必每次都做完整大范围 0.01 V 精扫。当前更倾向于使用三点搜索:

```text
测 center - step
测 center
测 center + step
```

判断规则:

```text
如果 center 最小: 当前点接近谷底, 保持或缩小窗口
如果 left 最小: 向负方向移动
如果 right 最小: 向正方向移动
```

适用对象:

| 通道 | 三点法指标 |
| --- | --- |
| P | 2200 Hz 最小 |
| I | 1000 Hz 最小 |
| Q | 1200 Hz 最小 |

三点法优点:

- 比完整细扫快。
- 适合围绕粗扫结果做局部精修。
- 能逐步逼近谷底。
- 便于后续扩展成闭环控制。

三点法风险:

- 初始点如果落在错误分支, 会沿错误方向搜索。
- 曲线太抖时, 三点判断会受噪声影响。
- P 路无 RF 或 2200 Hz 太弱时, 可能追噪声。

## 6. 闭环控制策略

### 6.1 闭环目标

闭环控制的目标是让三路分别维持在各自指标的最小点附近:

```text
P: 2200 Hz 最小
I: 1000 Hz 最小
Q: 1200 Hz 最小
```

三路同样重要:

- P 决定正交点和 I/Q 交调抑制。
- I/Q 决定子调制器 MITP 和载波抑制。
- I/Q 改变后 P-QTP 会移动。
- P 改变后 I/Q 曲线也可能变化。

因此闭环采用坐标轮询, 每次只调整一路。

### 6.2 当前推荐轮询顺序

当前推荐闭环顺序:

```text
P -> I -> Q -> P -> I -> Q -> ...
```

采用该顺序的原因:

- P-QTP 对最终交调抑制很敏感。
- I/Q 也必须参与, 否则载波抑制会漂移。
- 每次只动一路, 便于判断该路调整是否改善目标指标。
- P/I/Q 循环能逐步适应三路耦合。

### 6.3 梯度式三点闭环

每次闭环 step 对当前轴执行:

```text
测 center
测 center - delta
测 center + delta
```

当前推荐:

```text
delta = 0.01 V
实际更新步长约为 0.003 V
```

如果左右某侧明显更好, 就朝该方向移动一个较小步长。如果中心已经最好, 则保持。

目标函数可使用:

```text
error = metric^2
```

这样功率越大惩罚越大, 接近谷底时更新更温和。

### 6.4 blocks 选择

| 通道 | blocks | 原因 |
| --- | --- | --- |
| I | 4 | 1000 Hz 一阶项较强, 需要较快响应 |
| Q | 4 | 1200 Hz 一阶项较强, 需要较快响应 |
| P | 10 | 2200 Hz 交调项较弱, 需要更高平均 |

### 6.5 中心保护与 hold-weak

闭环最怕在谷底附近被噪声推走。因此需要中心保护:

```text
如果 center 与 left/right 差异很小
或者 center 已经足够接近最优
则不更新偏压
```

这种状态可以理解为:

```text
hold-weak
```

它的作用是:

- 避免微小噪声导致方向误判。
- 避免在尖锐 MITP 谷底附近来回抖动。
- 避免 P-QTP 弱信号时追踪噪声。
- 保持已经找到的好点。

### 6.6 锚点和安全窗口

`lock start` 时应记录当前 I/Q/P 为锚点。闭环更新不应无限漂移, 应限制在锚点附近的安全窗口内。

当前经验参数:

```text
I/Q anchor window ≈ ±0.20 V
P anchor window   ≈ ±0.30 V
```

如果某一路连续多次触发边界、指标恶化或中心保护失败, 应暂停闭环或要求重新找点。

## 7. 当前已确认经验

### 7.0 固件与脚本的角色边界

当前系统中, 固件和脚本的职责应保持清晰:

| 模块 | 职责 |
| --- | --- |
| 固件 | 导频输出、偏压输出、ADC 采集、Goertzel 指标提取、`auto coarse`、`auto fine`、`lock start` |
| 脚本 | 串口自动执行、保存原始日志、解析 CSV、画阶段图、离线验证新策略 |

原则:

```text
已经验证稳定的找点/控制策略, 应逐步固化到固件;
脚本用于实验编排和快速验证, 不应长期承担核心控制逻辑。
```

这样可以避免同一条实验流程在“脚本版”和“固件版”之间出现细节差异, 导致实验结果无法复现。

### 7.1 信号链路经验

- 导频必须连续打开, 扫描和采集不能假设扫描命令自动生成导频。
- ADC 采样率、Goertzel 频点、电脑端 FFT 必须完全一致。
- 之前采样率/频点不一致会导致功率低十几到二十 dB。
- 1000 Hz 和 1200 Hz 一阶项能稳定用于 I/Q 判断。
- 2200 Hz 能用于 P-QTP, 但需要足够信噪比。
- 200 Hz 低频项不适合作为主控制指标。

### 7.2 找点经验

- MATP 是相位锚点, 不是最终工作点。
- I/Q 平台点是为了让 P 路可观测, 不是最终 I/Q 偏压。
- 隐式解会制造假谷底和假平台。
- I/Q MITP 应使用“一阶局部谷底 + DC 辅助”判断。
- P-QTP 必须看 2200 Hz 曲线质量, 不能盲信单点最小值。
- 正支路和负支路都可能是真实 QTP, 不能简单认为负支路错误。

### 7.3 RF 经验

- 加 RF 时 P-QTP 曲线明显更可靠。
- 不加 RF 时 2200 Hz 可能接近噪声或杂散。
- 如果目标是实际带 RF 工作状态, 找点和闭环应在 RF 打开条件下验证。

### 7.4 不同调制器经验

不同调制器曲线形态差异很大:

- 有的调制器 MATP/MITP 曲线非常清晰。
- 有的调制器隐式解明显。
- 有的调制器 P-QTP 在无 RF 下几乎不可用。
- 算法必须能处理多分支、隐式解和边界截断。

### 7.5 典型异常及判断

| 现象 | 优先怀疑 |
| --- | --- |
| I/Q 一阶功率整体偏低十几 dB | ADC 采样率或 Goertzel 频点错配 |
| P-QTP 曲线浅且抖 | 2200 Hz 太弱、RF 未开、I/Q 平台不可观测 |
| 第一个点异常低并被选中 | 起始点瞬态、settle 不足或边界毛刺 |
| MATP 曲线中间出现额外深谷 | 隐式解或非目标分支 |
| 闭环越锁越差 | 目标频率信噪比不足、梯度方向被噪声误导、锚点窗口过宽 |
| 光谱仪载波抑制在好坏间差约 5 dB | I/Q MITP 仍有慢漂或闭环更新被噪声扰动 |

## 8. 当前仍需优化的问题

### 8.1 P-QTP 质量门限

需要定义 P-QTP 曲线是否可信, 建议考虑:

- 2200 Hz 动态范围是否足够。
- 谷底是否在边界。
- 谷底是否由连续趋势形成。
- 谷底是否只是单点毛刺。
- RF 开关状态是否符合实验目标。

### 8.2 平台候选验证

单个 I/Q 平台点可能被隐式解污染。更稳妥的方法是:

```text
I 路提取 1~2 个高分平台候选
Q 路提取 1~2 个高分平台候选
组合后做短 P-QTP 验证
选择 2200 Hz 曲线最可信的 I/Q 组合
```

为了控制扫描时间, 当前可以先只选每路最高分平台, 但保留后续扩展到多候选验证的接口。

### 8.3 长时间稳定性

需要继续记录:

- 5 min 锁定曲线。
- 10 min 锁定曲线。
- 30 min 锁定曲线。
- 光谱仪载波抑制变化。
- P/I/Q 偏压漂移量。
- lock error 和 applied step 变化。

如果光谱仪最佳和最差状态仍有约 5 dB 差异, 说明闭环仍存在慢漂、误调或测量噪声影响, 需要继续优化中心保护、更新步长和质量门限。

## 11. 阶段性结论

当前方案已经形成完整闭环:

```text
理论模型 -> 频率指标 -> 自动找点 -> 小窗口精修 -> 低速闭环
```

最核心的认识是:

```text
I/Q MATP 用来建立相位参考和寻找 P 路可观测区;
I/Q MITP 才是最终载波抑制目标;
P-QTP 依赖 2200 Hz 交调项, 但其可观测性强烈依赖 I/Q 初值和 RF 工况;
隐式解会污染平台判断, 所以必须结合曲线连续性、平台宽度、DC 和 P-QTP 验证;
闭环采用 P -> I -> Q 轮询梯度法, 每次只微调一路, 并通过中心保护避免被噪声带走。
```

后续重点不是重做基础链路, 而是增强:

- P-QTP 曲线质量判断。
- 隐式解下的平台候选筛选。
- RF 工作状态下的找点一致性。
- 长时间闭环稳定性。
