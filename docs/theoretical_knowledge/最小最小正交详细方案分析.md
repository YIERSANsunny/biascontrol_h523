## 一、链路构造
1. 主体器件：DPMZM，内部包含上路子调制器（I 路）、下路子调制器（Q 路）和一个主调制器（P 路）
2. 采用双导频信号：在 I 路和 Q 路的直流偏置电压（DC）输入口，分别叠加注入两个频率不同小幅度导频信号，
3. 反馈链路：DPMZM 输出的光信号通过一个 9:1 的光耦合器（OC）分束，取其中光功率较小的一路作为反馈信号。

## 二、理论分析
目标：目标是将 I 路、Q 路、P 路 分别控制在 MITP、MITP、QTP 。这三个点对应的理想相移分别为 $\pi$，$\pi$，$\pi/2$。

直流电压引入的相位差分别为：
$$\phi_I = \pi V_{DC,I} / V_{\pi,I}, \quad \phi_Q = \pi V_{DC,Q} / V_{\pi,Q}, \quad \phi_P = \pi V_{DC,P} / V_{\pi,P}$$

非理想因子为：
$$\delta_I, \delta_Q, \delta_P$$

在此基础上，该方案在上下两路子调制器的直流电压输入口分别加入两个频率不同的导频信号，假设上路导频表示为：$f_I = V_I \sin(\omega_I t)$ 而下路导频表示为 $f_Q = V_Q \sin(\omega_Q t)$

二者引入的相移可分别表示为 $\alpha = \pi V_I / V_{\pi,I} \quad \beta = \pi V_Q / V_{\pi,Q}$。三个调制器的直流电压输入口加载的电信号引入的总相移可分别写为
$$\varphi_I = \phi_I + \alpha \sin(\omega_I t), \quad \varphi_Q = \phi_Q + \beta \sin(\omega_Q t), \quad \varphi_P = \phi_P$$

输入到 DPMZM 的归一化输出光功率公式为：
$$I_{DPMZM} = \eta E_{out}(t) \cdot E_{out}(t)^* = I_{id} + I_{syn} + I_{nsyn} + o(\delta_k)$$

我们可以将 PD 拍频输出的电信号分为 5 个部分，分别为 $I_{id}$ 表示的是理想输出项；$I_{syn}$ 表示的是一阶极小量 $O(\delta_k)$ 中与理想输出项变化趋势相同的同步变化项；$I_{nsyn}$ 表示的是一阶极小量 $O(\delta_k)$ 中与理想输出项变化趋势不同的非同步变化项；在实际使用中 $I_{nsyn}$ 为导致 DPMZM 输出不符合理论的主导项，$o(\delta_k)$ 功率太小，可忽略不计。

其中：
$$I_{id} = \frac{\eta P_{in}}{8} \left[ 2 + \cos(\varphi_I) + \cos(\varphi_Q) + 4 \cos\left(\frac{\varphi_I}{2}\right) \cos\left(\frac{\varphi_Q}{2}\right) \cos(\varphi_P) \right]$$

$$I_{syn} = \frac{\eta P_{in}}{8} \left[ \begin{aligned} &2(\delta_I + \delta_Q + \delta_P) \\ &+ 2(\delta_I + \delta_P)\cos(\varphi_I) + 2\delta_Q\cos(\varphi_Q) \\ &+ 4(\delta_I + \delta_Q + \delta_P)\cos\left(\frac{\varphi_I}{2}\right) \cos\left(\frac{\varphi_Q}{2}\right) \cos(\varphi_P) \end{aligned} \right]$$

$$I_{nsyn} = \frac{\eta P_{in}}{8} \left[ \begin{aligned} &4\delta_I \sin\left(\frac{\varphi_I}{2}\right) \cos\left(\frac{\varphi_Q}{2}\right) \sin(\varphi_P) \\ &- 4\delta_Q \cos\left(\frac{\varphi_I}{2}\right) \sin\left(\frac{\varphi_Q}{2}\right) \sin(\varphi_P) \end{aligned} \right]$$

单片机主要检测三个频率分量：
1. 导频交调项（$(f_I \pm f_Q)$ 分量）
   $$I_{I\_Q} = 2\mu\eta P_{in} \sin(\omega_Q t) \sin(\omega_I t) \times \left[ \begin{aligned} &(1 + \delta_I + \delta_Q + \delta_P) J_1\left(\frac{\alpha}{2}\right) J_1\left(\frac{\beta}{2}\right) \sin\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) \cos(\phi_P) \\ &- \delta_I J_1\left(\frac{\alpha}{2}\right) J_1\left(\frac{\beta}{2}\right) \cos\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) \sin(\phi_P) \\ &+ \delta_Q J_1\left(\frac{\alpha}{2}\right) J_1\left(\frac{\beta}{2}\right) \sin\left(\frac{\phi_I}{2}\right) \cos\left(\frac{\phi_Q}{2}\right) \sin(\phi_P) + o(\delta_k) \end{aligned} \right]$$

2. 上路导频基频分量（$f_I$ 分量）
   $$I_I = \frac{\mu\eta P_{in} \sin(\omega_I t)}{16} \times \left[ \begin{aligned} &-2(1 + 2(\delta_I + \delta_P))\sin(\phi_I) \\ &-4(1 + \delta_I + \delta_Q + \delta_P)\sin\left(\frac{\phi_I}{2}\right)\cos\left(\frac{\phi_Q}{2}\right)\cos(\phi_P) \\ &+4\delta_I \cos\left(\frac{\phi_I}{2}\right)\cos\left(\frac{\phi_Q}{2}\right)\sin(\phi_P) \\ &+4\delta_Q \sin\left(\frac{\phi_I}{2}\right)\sin\left(\frac{\phi_Q}{2}\right)\sin(\phi_P) + o(\delta_k) \end{aligned} \right]$$

3. 下路导频基频分量（$f_Q$ 分量）
   $$I_Q = \frac{\mu\eta P_{in} \sin(\omega_Q t) J_1(m_Q)}{16} \times \left[ \begin{aligned} &-2(1 + 2\delta_Q)\sin(\phi_Q) \\ &-4(1 + \delta_I + \delta_Q + \delta_P)\cos\left(\frac{\phi_I}{2}\right)\sin\left(\frac{\phi_Q}{2}\right)\cos(\phi_P) \\ &-4\delta_I \sin\left(\frac{\phi_I}{2}\right)\sin\left(\frac{\phi_Q}{2}\right)\sin(\phi_P) \\ &-4\delta_Q \cos\left(\frac{\phi_I}{2}\right)\cos\left(\frac{\phi_Q}{2}\right)\sin(\phi_P) + o(\delta_k) \end{aligned} \right]$$

## 三、找点流程

**1、找寻 I 路和 Q 路 MATP**

$$I_Q = \frac{\mu\eta P_{in} \sin(\omega_Q t) J_1(m_Q)}{16} \times \left[ \begin{aligned} &-2(1 + 2\delta_Q)\sin(\phi_Q) \\ &-4(1 + \delta_I + \delta_Q + \delta_P)\cos\left(\frac{\phi_I}{2}\right)\sin\left(\frac{\phi_Q}{2}\right)\cos(\phi_P) \\ &-4\delta_I \sin\left(\frac{\phi_I}{2}\right)\sin\left(\frac{\phi_Q}{2}\right)\sin(\phi_P) \\ &-4\delta_Q \cos\left(\frac{\phi_I}{2}\right)\cos\left(\frac{\phi_Q}{2}\right)\sin(\phi_P) + o(\delta_k) \end{aligned} \right]$$

占主导部分的为 $I_{id}$ 展开部分，令 $I_{id}$ 展开部分等于 0 可得：

$$\sin\left(\frac{\phi_Q}{2}\right)\left( \cos\left(\frac{\phi_Q}{2}\right) + \cos\left(\frac{\phi_I}{2}\right)\cos(\phi_P) \right) = 0$$

$I_{id}$ 展开部分关于 $\phi_Q = 0$ 奇对称，且在 $\phi_Q$ 变化 $2V_\pi$ 内存在两个功率为 0 的解，其中一个解为 $\phi_Q = 0$，所以，理想情况下，可以通过扫描寻找 Q 路一阶功率最小点，再判断在该点处功率曲线是否对称来确认 $\phi_Q = 0$ 的点位。接下来分析，非理想情况，当 $\phi_Q$ 不接近 0，此时 $I_{id}$ 占主导，功率曲线仍然关于 $\phi_Q = 0$ 偶对称；当 $\phi_Q$ 趋于 0，此时 $\cos(\phi_Q / 2)$ 可近似等于 1，便可以得到：

$$\sin\left(\frac{\phi_Q}{2}\right) = \frac{-\delta_Q \cos\left(\frac{\phi_I}{2}\right) \sin(\phi_P)}{[(1 + 2\delta_Q) + (1 + \delta_I + \delta_Q + \delta_P)A + \delta_I B]}$$

$$\begin{cases} A = \cos\left(\frac{\phi_I}{2}\right) \cos(\phi_P) \\ B = \sin\left(\frac{\phi_I}{2}\right) \sin(\phi_P) \end{cases}$$

将 $\phi_I$ 和 $\phi_P$ 看作常数，其结果仍然可以看成关于 $\phi_Q = 0$ 偶对称，但是当 $\phi_I$ 和 $\phi_{XP}$ 初值分别接近 MATP 和 MITP 时，功率曲线就不关于 $\phi_Q = 0$ 偶对称，所以实际找点时在出现功率曲线无偶对称功率最小点时，可以调节 $\phi_I$ 和 $\phi_P$ 使得其满足功率曲线关于 $\phi_Q = 0$ 偶对称这一条件，因此可以用 Q 路一阶信号功率最小点来找寻可能为 MATP 的两个偏压点，再用功率变化曲线是否关于该点对称确认其为 MATP 点，同时寻找 Q 路的 MATP 不需要考虑 I 路和 P 路偏压点位必须工作在某一特殊点位，只需避开某一特殊点位即可。

同理 I 路 MATP 点也可以确定。接下来确定 P 路 QTP 点

**2、找寻 P 路 QTP**

$$I_{I\_Q} = 2\mu\eta P_{in} \sin(\omega_Q t) \sin(\omega_I t) \times \left[ \begin{aligned} &(1 + \delta_I + \delta_Q + \delta_P) J_1\left(\frac{\alpha}{2}\right) J_1\left(\frac{\beta}{2}\right) \sin\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) \cos(\phi_P) \\ &- \delta_I J_1\left(\frac{\alpha}{2}\right) J_1\left(\frac{\beta}{2}\right) \cos\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) \sin(\phi_P) \\ &+ \delta_Q J_1\left(\frac{\alpha}{2}\right) J_1\left(\frac{\beta}{2}\right) \sin\left(\frac{\phi_I}{2}\right) \cos\left(\frac{\phi_Q}{2}\right) \sin(\phi_P) + o(\delta_k) \end{aligned} \right]$$

为了避免 $I_{nsyn}$ 的影响，我们需要避免 I 路和 Q 路处于最大工作点附近，即满足 $\delta_I = \delta_Q = 0$ 点位附近，当不处于该点附近，此时 $I_{id}$ 占主导，通过找寻信号功率最小点即为 P 路的正负正交点处。

**3、找寻 I 路和 Q 路 MITP**

将 Q 路设置在 MATP，P 路设置在 QTP，此时 I 路一阶信号可化简为：

$$I_I = \frac{\mu\eta P_{in} \sin(\omega_I t) J_1(m_I)}{16} \left\{ \begin{aligned} &-2(1 + 2(\delta_I + \delta_P))\sin(\phi_I) \\ &+ 4\delta_I \cos\left(\frac{\phi_I}{2}\right) + o(\delta_k) \end{aligned} \right\}$$

令其为 0，舍去高阶分量，上述式子存在两个解，一个为 $\phi_Q = 0$，另一个为趋于 $\phi_Q = \pi$，由于前面找到了 $\phi_Q = 0$ 时得解，舍去该解，可得：

$$\sin(\phi_I) = \frac{2\delta_I}{1 + 2(\delta_I + \delta_P)}$$

同理：

$$\sin(\phi_Q) = -\frac{2\delta_Q}{1 + 2\delta_Q}$$

这两个解便为 MITP 对应的解

## 四、控制流程

在第三步找到 P 路 QTP，I 路和 Q 路 MITP 的基础上。先在 I 路和 Q 路加入导频信号，调节 P 路电压，找寻 $I_{I\_Q}$ 的功率最小点，控制 P 路在 QTP 处，然后在 I 路和 Q 路先后加入导频，调节对应直流偏压，便可将 I 路和 Q 路控制在 MITP 附近，此时，二者偏压角度满足下式：

$$\sin(\phi_I) = \frac{2\delta_Q}{1 + 2(\delta_I + \delta_P)}$$

$$\sin(\phi_Q) = -\frac{2\delta_I}{1 + 2\delta_Q}$$

此时，循环上述控制过程便可完成 DPMZM 最小最小正交点偏压控制。
