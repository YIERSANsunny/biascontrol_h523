## 2. 固定链路结构与器件参数

### 2.1 连续波光源模块

提供系统的光载波输入，核心模块路径为 `CW_DSM -> Power N`。

- 发射频率（EmissionFrequency）：`193.1e12 Hz`
- 平均光功率（AveragePower）：`0.010 W`
- 线宽（Linewidth）：`25e3 Hz`
- 相对强度噪声（RIN）：`-175 dB/Hz`

### 2.2 DPMZM 核心调制模块

链路主体由两个平行子 MZM（I 路、Q 路）和主调制器（P 路）组成。

子 MZM（`DiffMZ_DSM`）固定参数如下：

- 直流半波电压（VpiDC）：`5 V`
- 射频半波电压（VpiRF）：`5 V`
- 插入损耗（InsertionLoss）：`6 dB`
- 消光比（ExtinctionRatio）：`30 dB`
- 工作模式：`LowerArmPhaseSense = NEGATIVE`

关于 `NEGATIVE` 推挽模式的说明：

- 该模式表示上下臂相移符号相反，总相移由上下臂电压差决定。
- 因此后续“偏置电压 -> 相位”的理解必须结合推挽差分驱动语境，而不能简单套用单端驱动直觉。
- 本文档不在这里固定某一个 I/Q/P 工作点，只说明链路采用这种物理模式。

### 2.3 光电检测与监测模块

DPMZM 输出后进入光电检测链路，提取频率分量用于理论验证和后续偏压判定。

- 光耦合器：`1:9`
- 光电探测器 Responsivity：`0.8 A/W`
- TIA 跨阻增益：`100000 Ohms`
- 观测模块：
  - 光功率计（`PowerMeter`）
  - 电信号波形与频谱分析仪（`SignalAnalyzer` 等）

## 3. 导频与检测链路固定配置

当前理论验证阶段采用双导频注入方案，对 I 路和 Q 路分别施加不同频率的小幅导频：

### 3.1 I 路导频

- 模块：`FuncSineEl`
- 振幅：`0.025 V`
- 频率：`1e3 Hz`

### 3.2 Q 路导频

- 模块：`FuncSineEl`
- 振幅：`0.025 V`
- 频率：`1.2e3 Hz`

这些固定配置的目的不是生成最终业务调制，而是服务于以下三个可观测频率分量的提取：

- `f_I`
- `f_Q`
- `(f_I \pm f_Q)`

其中：

- `f_I` 主要用于 I 路偏压判定
- `f_Q` 主要用于 Q 路偏压判定
- `(f_I \pm f_Q)` 主要用于 P 路正交点判定

## 4. 可变验证参数

以下参数在当前理论验证阶段**不是固定链路属性**，而是根据验证目标动态调整的工况参数：

- I 路直流偏置
- Q 路直流偏置
- P 路相位偏移
- 当前锁定点或初始点
- 扫描对象（I / Q / P）
- 扫描范围
- 扫描步进
- 是否固定其余两路在某一参考工况

因此，文中若出现类似 `Q ≈ 2.21 V`、`P = 140°`、`P 扫描 0°-180°` 这样的值，应理解为**某次验证工况中的设置**，而不是整条链路的永久默认值。

## 5. 当前已使用的典型验证工况

### 案例 A：I/Q 粗找 MATP 与隐式解分析

用途：

- 验证 I/Q 路 MATP 是否可识别
- 验证隐式解是否存在
- 验证隐式解附近曲线是否呈现不对称性

典型设置：

- 导频保持为当前基础链路固定配置
- Q 路取参考偏置约 `2.21 V`
- P 路取参考相位约 `140°`
- 扫描对象为 I 路偏置

说明：

- 这里的 `Q ≈ 2.21 V` 与 `P = 140°` 是为了探索隐式解而选取的特定验证点位，不代表链路默认工作点。

### 案例 B：P 路 QTP 搜索

用途：

- 验证 P 路正交点搜索逻辑
- 验证非理想条件下 QTP 相对理论 `90°` 的漂移

典型设置：

- 导频保持为当前基础链路固定配置
- P 路作为扫描对象
- 扫描范围为 `0°-180°`
- 共 `181` 个点，步进 `1°`

结果摘要：

- 当前数据中，P 路候选 QTP 位于 `93°`
- 该结果说明在器件失配、有限消光比等非理想项存在时，P 路真实 QTP 不再固定在理论 `90°`，而会为了抵消非理想误差项漂移到新的最优点（当前数据中约为 `93°`）

说明：

- 这里的 `0°-180°` 扫描是为了执行 P 路正交点搜索，不代表链路始终处于全范围扫描状态。

对应证据：
