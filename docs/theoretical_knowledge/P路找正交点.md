## 1. I/Q 路为什么要先寻找 MATP（最大传输点）？

本方案的终极目标是将 I 路和 Q 路稳定在**最小传输点（MITP，理想相移 $\phi \approx \pi$）**。第一步去寻找最大传输点（MATP，理想相移 $\phi \approx 0$），完全是为了时序解耦和建立绝对相位参考，具体逻辑如下：

### 1.1 MATP 作为“绝对锚点”的数学特性
在系统刚上电时，P、I、Q 三路的偏置状态是未知的、随机耦合的。以 I 路为例，其一阶理想信号幅度正比于：
$$|I_{I(ideal)}| \propto \left| \sin\left(\frac{\phi_I}{2}\right) \left[ \cos\left(\frac{\phi_I}{2}\right) + \cos\left(\frac{\phi_Q}{2}\right)\cos(\phi_P) \right] \right|$$

我们将后半部分受 Q 路和 P 路随机状态影响的项记为未知常数 $C$。
* **若直接寻找 MITP ($\phi_I = \pi$)**：此时 $\sin(\pi/2) = 1$，$\cos(\pi/2) = 0$。一阶信号幅度变为 $|1 \times (0 + C)| = |C|$。由于 $C$ 的不确定性，MITP 处的一阶信号既不凸起也不是极小值，在扫描曲线上无法作为一个特征点被程序稳定识别。
* **若先寻找 MATP ($\phi_I = 0$)**：此时 $\sin(0) = 0$，$\cos(0) = 1$。一阶信号幅度变为 $|0 \times (1 + C)| = 0$。**由于外部正弦因子的清零作用，MATP 能够强行屏蔽其他两路的串扰影响**，在扫描曲线上表现为一个非常深且稳定的极小值（凹坑）。因此，系统利用寻找 MATP 来完成粗定位并建立准确的相位坐标系。

### 1.2 为什么必须将偏置推离 MATP？
完成粗定位后，系统进入寻找 P 路正交点（QTP）的阶段。控制 P 路依赖于导频交调项 $(f_I \pm f_Q)$，其主导项正比于：
$$I_{I\_Q} \propto \sin\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) \cos(\phi_P)$$

如果 I 路和 Q 路此时仍停留在 MATP（$\phi_I = 0, \phi_Q = 0$），则上述交调信号将被彻底清零，导致 P 路完全失去对偏压变化的灵敏度（即落入“盲区”）。
因此，必须将 I/Q 两路推离 MATP，使其推至 MITP 邻域并保留少量偏移量。这不仅保证了 P 路交调项具备足够的可观测性，也为后续闭环锁定 MITP 铺平了道路。

## 2. P 路正交点（QTP）发生角度漂移的理论机理

在对 P 路进行 $0^\circ \sim 180^\circ$ 扫描时（共181个点），实际观测到的交调项功率极小值点并未出现在理想的第91点（$90^\circ$）处，而是发生了偏移（例如仿真中出现在第94个点，对应 $93^\circ$）。这种偏移并非实验或仿真误差，而是器件非理想因素引发的必然物理现象。

### 2.1 漂移的数学推导
根据导频交调项 $I_{I\_Q}$ 的表达式，当交调项达到极小值（即过零点）时，其内部各项必须相互抵消。令交调方程近似为零并移项，可得：

$$
\cos(\phi_P) \cdot \left[ (1 + \Sigma\delta) \sin\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) \right] = \sin(\phi_P) \cdot \left[ \delta_I \cos\left(\frac{\phi_I}{2}\right) \sin\left(\frac{\phi_Q}{2}\right) - \delta_Q \sin\left(\frac{\phi_I}{2}\right) \cos\left(\frac{\phi_Q}{2}\right) \right]
$$

### 2.2 漂移的物理意义：非理想项的“自动补偿”
* **理想器件中**：器件不存在失配（$\delta_I = 0, \delta_Q = 0$），等式右侧完全为零。为使等式成立，必须要求 $\cos(\phi_P) = 0$，即 $\phi_P$ 严格等于 $90^\circ$。
* **实际非理想器件中**：由于消光比有限、耦合分光比不均等因素，$\delta_I$ 与 $\delta_Q$ 不为零，导致等式右侧变为一个非零常数。为了使等式两边重新平衡，**$\cos(\phi_P)$ 绝不能为零**。这就强制要求系统在实际锁定时，$\phi_P$ 必须偏离 $90^\circ$（例如相移至 $93^\circ$），利用产生的非零 $\cos(\phi_P)$ 值来抵消右侧的误差项。

### 2.3 工程指导意义
这种漂移本质上是闭环反馈系统对 DPMZM 器件内部串扰与非理想特性的**自适应补偿**。它证明了：
1.  不能采用开环方式将 P 路电压死板地固定在物理定义的 $90^\circ$ 处，否则系统性能将劣化。
2.  必须采用闭环控制策略，追踪交调误差信号的极小点（或同步检波的过零点）。系统自动寻找并稳定在偏离的真实工作点（如 $93^\circ$），正是非理想条件下实现最佳调制状态的表现。
